# Javi's Week in Michigan 💛

A personal itinerary page for Nov 10–16, 2026: two mini trips (Ann Arbor + Columbus), day-by-day schedule, love coupons, passport, Connections game and more.

Everything lives in one file, `index.html`. Photos are embedded, so there are no other assets to upload.

Progress (checkmarks, stamps, redeemed coupons, scores) is saved in each viewer's own browser.
